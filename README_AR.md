# Alblozy Android

هذا المشروع يحول نسخة Alblozy v72 الحالية إلى تطبيق Android يعمل داخل WebView.

- اسم التطبيق: Alblozy
- package: com.alblozy.app
- version: 72.0
- min Android: 6.0 (API 23)
- الاتجاه: عمودي
- ملف الواجهة: app/src/main/assets/index.html

لبناء APK باستخدام Android Studio: افتح هذا المجلد ثم Build > Build APK(s).
